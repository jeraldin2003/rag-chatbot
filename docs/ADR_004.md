# ADR-004: Model Selection Recommendation — API vs. Open-Source for Production RAG

**Scope:** Week 10 Capstone Deliverable — Model Selection & Shipping Recommendation

---

## 1. Context & Business Need
In Week 10, the RAG Chatbot v2 was evaluated against an automated 11-test benchmark suite comparing an **API-based model** (`Gemini 1.5 Flash`) against a **Self-Hosted Open-Source model** (`Ollama qwen2.5:1.5b` / `phi3`).

The production evaluation evaluated three primary axes:
1. **Accuracy / Groundedness** (% test cases passed, keyword precision, adherence to refusal rules)
2. **Latency** (Average response time per user query in milliseconds)
3. **Economics / Operating Cost** (Token cost per query vs infrastructure hosting overhead)

---

## 2. Evaluation Results Summary

| Metric | API Model (`Gemini 1.5 Flash`) | Open-Source Model (`Ollama qwen2.5:1.5b`) |
| :--- | :--- | :--- |
| **Accuracy / Pass Rate** | **100% (11/11)** | 63.6% (7/11) |
| **Average Latency** | **~850 ms** | ~4,200 ms (on standard CPU hardware) |
| **Refusal Compliance** | **Strict & Grounded** (Declines irrelevant queries cleanly) | Hallucinates or answers hesitantly on irrelevant inputs |
| **Estimated Query Cost** | ~$0.00012 / query ($0.12 / 1,000 queries) | $0 token cost + $50–$150/mo GPU server hosting |
| **Infrastructure Risk** | Zero GPU management; cloud managed API | High DevOps overhead; requires dedicated GPU instances |

---

## 3. Decision
**Recommendation: Ship the API-based model (`Gemini 1.5 Flash`) for production deployment.**

---

## 4. Rationale & Trade-off Analysis

### Why Gemini 1.5 Flash Wins for Production:
1. **Superior Instruction Adherence & Groundedness**:
   - `Gemini 1.5 Flash` strictly follows system prompts requiring bracketed inline citations (`"[POSH_POLICY.pdf]"`) and reliably declines irrelevant queries with the exact required refusal message (`"I don't have enough information in the uploaded documents to answer that."`).
   - Small open-source models (1.5B parameters) frequently hallucinate or generate wordy responses that violate strict refusal constraints.

2. **Latency & User Experience**:
   - Gemini averages **~850 ms** end-to-end response time over HTTPS.
   - Ollama on CPU hardware averages **>4 seconds** per turn, creating prohibitive latency for interactive chat applications.

3. **Total Cost of Ownership (TCO)**:
   - At ~$0.00012 per query, 10,000 user queries per month cost **~$1.20** on Gemini API.
   - Self-hosting an Ollama GPU instance (e.g. AWS `g4dn.xlarge` or T4 instance) costs **~$300/month** minimum, which is cost-prohibitive at low to medium query volumes.

---

## 5. When to Re-evaluate Open-Source
Open-source self-hosting should be revisited if:
1. **Strict Data Privacy / On-Premise Compliance**: Data residency rules forbid any external API call outside corporate networks.
2. **High Scale Scale-Out**: Query volume exceeds 5,000,000 queries/month, where fixed GPU infrastructure costs become cheaper than per-token API costs.

---

## 6. Consequences
- Production default route set to `/chat/gemini`.
- Zero GPU server provisioning needed for deployment.
- Strict API key management and rate-limit handling enforced in environment configs.
