# ADR-002: RAG Chatbot v2 — Evaluation Harness

**Scope:** Week 10 assignment (partial — see note)

## Context
Week 10 asks for hybrid search, conversation memory, source citation, refusal on low-confidence answers, and a 10-question eval harness comparing models. So far only the eval harness is built — the rest is still open.

## Decision
- Built the eval harness first, before touching retrieval/memory/citation, so we'd have a way to actually measure whether later changes help.
- Wrote 10 Q&A pairs with reference answers pulled from the real uploaded PDFs, not guessed.
- Scored by keyword match against each answer, plus type-specific checks (irrelevant → must decline, empty query → must 400).
- Log the raw model answer next to pass/fail, since keyword matching alone gave false failures on the first run.

## Alternatives Considered
- Build hybrid search before the eval harness — rejected, no way to tell if it actually helped without a scoring baseline first.
- LLM-as-judge scoring — considered, skipped for now due to added cost/complexity per question.
- Exact-match scoring — rejected, real answers never match a reference word-for-word.

## Consequences
- First real run caught a genuine bug: `qwen2.5:1.5b` answers confidently on irrelevant questions instead of declining.
- Keyword scoring has false failures (e.g. "6 months" vs "six months" counted as different) — needs a fix before the score % can be trusted.
- Hybrid search, re-ranking, conversation memory, inline citations, and reliable refusal are still not built — this ADR will need a follow-up once they are.
